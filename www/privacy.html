디지털 안심 체크

개인정보처리방침

시행일: 2026년 11월 6일

1. 수집하는 개인정보

디지털 안심 체크(이하 “앱”)는 이름, 연락처, 계정, 위치, 기기 식별자 등 어떠한 개인정보도 수집하지 않습니다. 회원가입과 로그인 기능이 없습니다.

2. 기기에 저장되는 정보

체크리스트 항목별 상태(완료·해당 없음·미확인)와 변경 시각, 마지막으로 연 점검 분야만 사용자의 기기(브라우저 또는 앱 내부 저장소)에 저장합니다. 이 정보는 개발자나 제3자에게 전송되지 않으며 암호화되지 않습니다. 앱의 ‘이 기기의 기록 모두 삭제’ 기능, 앱 삭제 또는 브라우저 데이터 삭제로 언제든지 지울 수 있습니다.

3. 외부 전송과 제3자 제공

앱은 분석·광고·추적 도구, 외부 서버, 외부 API를 사용하지 않으며 정보를 제3자에게 제공하지 않습니다. 사용자가 직접 ‘내보내기’ 또는 ‘공유’를 선택한 경우에만 사용자가 고른 앱이나 위치로 기록이 전달됩니다.

4. 권한

안드로이드 앱은 인터넷 권한 외의 권한(위치, 연락처, 카메라, 저장소 등)을 요청하지 않습니다. 앱은 차량, 주거 기기, 클라우드 계정에 접근하지 않습니다.

5. 웹 버전 접속 기록

웹 버전(GitHub Pages)에 접속하면 호스팅 사업자(GitHub)가 일반적인 서버 접속 기록을 남길 수 있습니다. 이는 GitHub의 개인정보 처리방침을 따릅니다.

6. 아동

앱은 아동을 대상으로 하지 않으며 아동의 정보를 수집하지 않습니다.

7. 변경과 문의

이 방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다. 문의는 GitHub 이슈로 남겨 주세요.
